TIKESHWAR BAGHEL — PORTFOLIO V3

Files:
- index.html: complete responsive portfolio website
- profile.jpg: add your own portrait in the same folder (optional)

How to use:
1. Extract this ZIP.
2. Add your photo and name it profile.jpg in the same folder as index.html.
3. Open index.html in a browser to preview.
4. For a public website, upload the folder to GitHub and deploy it with GitHub Pages or Vercel.

Included:
- Forest green, warm ivory and copper colour palette
- Dark/light theme toggle
- Responsive navigation and mobile menu
- Animated hero and scroll reveal
- About, academics, detailed semester record, projects, NSS leadership,
  grouped skills, certifications, achievements and contact sections

Note: Certificate cards currently show credential details. Add the original PDF files
inside a certificates folder and link them in index.html if you want direct PDF previews.
